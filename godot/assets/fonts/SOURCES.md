# Character interface typography

Barlow Regular and SemiBold, and Barlow Condensed SemiBold, by Jeremy Tribby.
Downloaded from the official [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/barlow)
and [Barlow Condensed directory](https://github.com/google/fonts/tree/main/ofl/barlowcondensed).

Both families use the SIL Open Font License 1.1. The original licence files are
included here and copied into the Windows distribution. Fonts are unmodified.
